## 型号定位

WX-26「惊雷」是一款：

> 低成本、国产化、可垂直起降的战术快速反应火力支援平台。

设计目标：

- 快速部署
- 低空近距支援
- 战场清扫
- 长时间巡逻
- 多用途任务适应

核心理念：

> 以较低成本获得高机动、高响应、高可靠性的VTOL战术航空平台。
